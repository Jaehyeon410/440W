# Fridge Remix — Frontend

React + Vite frontend for the Fridge Remix app.

See the root [README.md](../README.md) for full project setup instructions.

## Quick start

```bash
cd app-react
npm install
cp .env.example .env
npm run dev
```

Open: http://127.0.0.1:3000

## Build for production

```bash
npm run build
```

Output goes to `app-react/dist/`.
